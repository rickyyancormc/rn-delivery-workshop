Detailed sections with talking points and demos

A. E2E reliability on the Login screen
Relevant commits: 0fc9d59, 09c81f7, e0db98c
Files touched:
- src/screens/Login/index.tsx: Added ScrollView (testID: login-scroll), adjusted content container spacing.
- e2e/starter.test.js: Added waitFor(...).whileElement(by.id('login-scroll')).scroll(...) to ensure inputs are visible; included taps on header logo to blur and trigger validation; keyboard visibility adjustments.
Key messages:
- Why scrolling matters: inputs can be off-screen on smaller devices/with keyboard.
- Deterministic E2E: waitFor + whileElement.scroll reduces flakiness.
Live demo:
- Start Metro and run Detox iOS or Android tests.
  - iOS: yarn detox:ios:build:ci && yarn detox:ios:test:ci
  - Android: yarn detox:android:build:ci && yarn detox:android:test:ci
Slide content:
- Snippets showing ScrollView and the Detox waitFor/whileElement usage.
- Before/After flakiness anecdote.

B. CI/CD best practices in release workflow
Relevant commits: ebb50a5, f062874, 237afe4, cda2b00 and earlier Android pipeline setup series.
Files touched:
- .github/workflows/release.yml
Key messages:
- Triggers preserved (push to tags v*, branch pipeline-config).
- Node setup via actions/setup-node@v4 with Yarn cache; Corepack enables Yarn 4.
- CocoaPods caching; Applesimutils for Detox.
- Emulator runner with KVM; test scripts invoked via yarn.
- iOS build and deploy via Fastlane after Detox tests; Android build and Play Store deploy via Fastlane.
- Permissions and concurrency (if present) to avoid overlapping runs; artifacts upload paths.
Live demo:
- Show workflow YAML highlights in GitHub UI.
- Trigger a dry run on a feature branch (skip store deploys in demo) or explain tag-triggered releases.
Slides:
- Diagram of jobs: build-ios and build-android; steps per job.
- Common pitfalls: caching, Metro server background process, artifact paths.

C. iOS App Icons integration
Relevant commits: ae2712b
Files touched:
- ios/RNDeliveryWorkshop/Images.xcassets/AppIcon.appiconset/* and Contents.json
Key messages:
- Asset catalog name must match ASSETCATALOG_COMPILER_APPICON_NAME=AppIcon.
- All required sizes for iPhone/iPad/marketing provided.
- If using a single 1024x1024 source, generate sizes with a tool (Sketch/Figma/xcodebuild assetutil/Icon Set Creator).
Live demo:
- Open Xcode, verify General > App Icons and Launch Images points to AppIcon.
- Run app on simulator to show icon.
Slides:

- Tip: Keep a script or design export preset.
